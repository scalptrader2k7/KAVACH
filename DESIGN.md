# KAVACH visual system

Refinement of the existing dark mission-console identity. Operate mode: make local command composition, receiver decisions, and evidence inspection clear to a first-time evaluator and an engineer.

Keep the existing KAVACH wordmark, copper primary action, DM Sans interface typography, IBM Plex Mono protocol typography, and synthetic satellite illustration. No live-system claims or ornamental monitoring graphs.

Tokens in web/src/styles.css: background #0b0f15, panel #111923, raised surface #182331, divider #304052, primary text #e5ecf4, secondary text #a6b4c6, focus #a4c5ff. Existing semantic green, red and amber remain paired with explicit words and symbols. Radius 7px; spacing rhythm 8px. Main operational text 12-15px, section headings 15-19px, result 24px, page title 32px. Mono is reserved for code, identifiers and measured values.

Use the receiver explanation as primary outcome text. Render key match, authentication and authorisation independently from their checks; never infer authorisation from sender_verified. Unknown or not-run facts remain explicit. Label scenario expectations as expectations. Persisted audit status must come from the receiver.

At <=1200px, use two work columns plus a separate state row. At <=720px, stack the workflow, widen controls, and retain horizontal table scrolling. Do not shrink evidence to fit desktop columns. All dialogs contain focus and restore it on close. Respect reduced motion.
