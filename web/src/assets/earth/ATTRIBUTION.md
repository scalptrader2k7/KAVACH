# Earth imagery

`blue-marble-2048.jpg` is NASA's 2048 × 1024 Blue Marble land/ocean/ice composite.

- Original image: https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.jpg
- Original collection: https://visibleearth.nasa.gov/collection/1484/blue-marble
- Credit: NASA / NASA Goddard Space Flight Center, Reto Stöckli; land imagery based on MODIS satellite observations.
- Usage guidelines: https://www.nasa.gov/nasa-brand-center/images-and-media/

This NASA-produced composite is distributed under NASA's image/media usage guidelines, with attribution. No NASA logo is used, and no endorsement is implied. This is a historical image composite, not live Earth imagery.

The downloaded JPEG is bundled locally without modification (266,599 bytes). The renderer adds lighting and rotation; its orientation and sunlight are illustrative, not an astronomical simulation. The same image is used in a static fallback when WebGL or texture loading is unavailable. There are no runtime requests to NASA or an image CDN.
